# SET v1.0.4 — Moodboard + Schedule

## Moodboard
- Delete any uploaded/imported image with confirmation.
- Full-screen View All lightbox with previous/next controls, keyboard arrows, Escape close, counter and thumbnail strip.
- Click any moodboard image to open the viewer.
- PDF export uses selected images when a selection exists; otherwise exports the whole moodboard.
- PDF uses a fixed 2x2 editorial contact-sheet layout with consistent margins and captions to avoid overlapping content.

## Schedule
- Schedule is scoped to the active project.
- Add/edit/delete schedule rows inline.
- Editable date, time, event title and location/notes.
- Stable desktop/tablet grid; mobile becomes stacked touch-friendly cards instead of overflowing cells.
