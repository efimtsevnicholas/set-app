# SET v0.6 — Finance Automation & Entitlements

Implemented in source:
- Shared finance-rule helpers for tax reserve, overdue days and late-payment calculations.
- Subscription entitlement helper shared by future web/mobile billing adapters.
- Supabase migration 003 with invoice line items, payment events, versioned French finance rule sets, collection actions and audit log.
- Database-level `has_set_pro_access()` entitlement function.
- Auditable collection queue: friendly reminder → due reminder → overdue reminders → formal notice draft.
- Formal notice remains `requires_approval=true`; the database workflow does not autonomously send legal correspondence.
- Provider identity fields for Stripe and Apple reconciliation.
- White / black / red mobile visual system aligned with the web application.

Current French defaults recorded as configurable reference data, not permanent legal constants:
- Micro BIC service social contribution reference: 21.2%.
- Micro BNC service social contribution reference: 25.6%.
- B2B recovery-fee reference: €40 where legally applicable.

Production activation still requires Supabase credentials, Stripe account/products/webhooks and Apple App Store Connect products/server notifications. E-invoicing/PDP integration is deliberately kept as a provider adapter boundary because French rollout and provider requirements are external and evolving.
