# SET v0.5 — Finance, Subscriptions & Editorial UI

Implemented in source:
- White / black / red editorial design system
- Finance workspace
- Invoice list and deposit/final invoice creation prototype
- Payment reminder workflow prototype
- French micro-business tax reserve estimator with editable rates
- Formal collection flow with mandatory owner approval before legal/formal communication
- Admin pricing controls: €9.99 monthly, €99.99 yearly, 7-day free trial
- Database foundation for billing plans, subscriptions, invoices, reminders and tax profiles
- Apple/Stripe product mapping fields

Production activation still requires external credentials and provider configuration (Supabase, Stripe, Apple App Store Connect). Tax/legal automation must use maintained rules and appropriate professional/legal review before autonomous production use.
