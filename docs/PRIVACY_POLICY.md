# SET Privacy Policy — Draft v1.0
Last updated: 31 August 2026

SET is a creative production workspace. This draft must be reviewed and published at a public URL before App Store submission.

## Data we process
- Account information (name, email, profile role)
- Project information and content entered by users
- Messages, tasks, schedules, budgets and contact records
- Files and images uploaded by users
- Technical and security information necessary to operate the service

## Why
We use this information to provide the workspace, authenticate users, synchronize collaboration, secure the service, and provide support.

## Sharing
Project content is shared only with users authorized for the relevant workspace, except where required by law or where service providers process data on our behalf.

## Security
Production storage must use encrypted transport, access controls, authenticated requests, and role-based project permissions.

## Retention and deletion
Users must be able to request account deletion. Project owners and collaborators must have clearly defined content retention rules.
