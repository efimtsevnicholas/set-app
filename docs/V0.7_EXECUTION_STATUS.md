# SET v0.7 execution status

Implemented in source code:

- Server-side Supabase admin/auth helpers.
- Stripe Checkout endpoint for monthly/yearly subscription with 7-day trial.
- Stripe webhook with idempotency check and subscription entitlement sync.
- Transactional email adapter for invoice delivery and payment reminders.
- Server-generated invoice PDF endpoint using pdf-lib.
- Invoice email endpoint with audit logging.
- Authenticated manual payment reconciliation endpoint.
- Cron-safe collection processor for non-legal reminders.
- Database constraint that formal notices always require explicit approval.
- Additional invoice client/currency fields and indexes.
- Node core tests for pricing, trial access, tax reserve and late-payment calculations.

Still requires external credentials / account actions before production:

- Supabase project URL, publishable key and service role key.
- Stripe products/prices, secret key and webhook secret.
- Resend API key and verified sending domain.
- Apple App Store Connect subscription products / credentials for iOS IAP verification.
- Production domain and cron scheduler.
- Legal/accounting review of invoice templates and configurable French tax rules before relying on them operationally.
