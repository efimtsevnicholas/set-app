# SET 1.0.5 — Casting Pro

Casting now supports five numbered client choices, professional talent cards, agency/contact information, measurements, availability, status workflow (New / Option / Hold / Confirmed / Released), internal/client notes, public external review links, styled casting PDFs and PDF delivery by email.

Public links are snapshot shares stored in `workspace_records` under kind `casting-share`. They open without a SET account. Email delivery uses the existing transactional email / Resend configuration.

Existing casting media remains in the same cloud collection (`media-casting`) so the upgrade keeps prior project casting data and enriches it with the new fields.
