# SET v1.0.5 — Calendar editing + invoice notes

- Calendar events open in a full editor with rename, delete, date/time edits, project assignment, attendee email, notes and quick move controls (±1 day / ±30 min / Today).
- Invoice/devis composer includes an optional comment/details field for the service line.
- Invoice/devis composer includes free-form Legal / Tax / Payment notes printed at the bottom of the PDF.
- Useful for user-reviewed wording such as `TVA non applicable, art. 293 B du CGI`; SET does not assert that a legal phrase applies automatically.
- Migration 012 adds optional `comment` columns to invoice_items and quote_items.
