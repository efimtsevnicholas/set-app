# SET 1.0.1 — Responsive Web Release

Responsive pass for desktop, iPad/tablets, iPhone and Android phones.

Covered viewport classes include compact desktop/large landscape tablets, 1024px tablets, 900px tablet/mobile shell, 700px phones/small tablets, 480px phones, 374px narrow phones, and short landscape devices.

Key fixes: safe-area support, touch targets, mobile form font sizing, responsive project/media/contact grids, horizontally scrollable calendar/budget/schedule where preserving structure is safer than crushing columns, viewport-constrained modals, mobile bottom navigation, and adaptive Call Sheet/Tasks/Finance layouts.
